## Overview

**TBR3** is a charity and donation platform designed to support donation-related workflows through a modern web interface.

My responsibility in this project focused on building the **React frontend client**, organizing the project structure, creating reusable UI components, building main application pages, and supporting a smooth user experience for visitors and users interacting with the platform.

This documentation focuses specifically on my **React frontend contribution**.

---

## My Role

I was responsible for building and organizing the React frontend side of the project.

My work included:

* Building the React client-side application
* Creating reusable UI components
* Structuring pages and layout sections
* Implementing responsive designs using Tailwind CSS
* Setting up navigation between pages using React Router
* Organizing frontend files and folders
* Supporting user-facing donation platform flows
* Building a maintainable frontend structure for future development

## Development Setup

### 1. Navigate to the client folder

```bash
cd client
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

The application runs locally on:

```text
http://localhost:3000
```

### 4. Build for production

```bash
npm run build
```

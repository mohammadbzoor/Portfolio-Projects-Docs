## Overview

The frontend layer of **TechNetwork** was built as a React.js single-page application designed to provide smooth experiences for developers, companies, and platform users.

My contribution focused on creating user-facing interfaces, connecting the frontend with backend APIs, handling data flow, and supporting recruitment-related features through clean and responsive UI components.

---

## My Frontend Role

As part of the frontend development work, I focused on:

* Building React.js pages and reusable UI components
* Creating user interfaces for developers and companies
* Implementing responsive layouts using Tailwind CSS and custom CSS
* Connecting the frontend with backend REST APIs using Axios
* Handling API responses and client-side data flow
* Building interfaces related to developer profiles, projects, jobs, and applications
* Supporting smooth user interaction across the recruitment platform
* Improving the user experience for portfolio browsing, job discovery, and candidate-related flows
